# Controladoria de prazos (painel externo)

Ele usa o mesmo Supabase deste projeto e depende destas tabelas:

**Ao renomear, remover ou mudar colunas/status dessas tabelas (ou as políticas RLS delas), revise o painel da controladoria.**
